# Peking University Red Theme Sources

- Theme type: Peking University academic report / paper presentation.
- Primary color: 北大红 (Beida Red), official Web value `#94070A`; the VI manual also lists RGB `R139 G0 B18`, CMYK `C0 M100 Y100 K45`, and PMS DS 821C / 821U.
- Official VI download page: `https://vim.pku.edu.cn/xzzq/`.
- Emblem archive: `https://vim.pku.edu.cn/docs/20240527144201516364.zip`, file `标志_红色.png`.
- Official horizontal lockup archive: `https://vim.pku.edu.cn/docs/20240527144451726806.zip`, file `标志与中英文校名组合规范_左右.png`.
- The shipped `brand_lockup.png` and `emblem_mark.png` are the official PNG assets, copied without redrawing, recoloring, or recomposing the seal or the calligraphic name.
- The VI manual recommends 方正大标宋 / 方正粗宋 for large titles and 方正中等线 for body text. This theme uses Noto Serif SC for display and Noto Sans SC for body/PPTX text as installed fallbacks; the official calligraphic name remains an image, never a typeset substitute.
- Seal clear space and minimum size: the official manual requires isolated clear space and a minimum emblem size of 7 mm × 7 mm. The header lockup is kept well above that floor.

The emblem and wordmark are school identity assets. This theme is provided so a Peking University presenter can produce a consistent internal academic deck. It does not imply Peking University authorship, endorsement, or ownership of the source paper. Confirm compliance with the university's visual identity rules before public or commercial use.
