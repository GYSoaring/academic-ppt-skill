# 南京大学标识来源

本主题中的院校标识来自南京大学校史博物馆公开校史页面，仅用于展示 `academic-ppt-skill` 的官方字标接入能力。

- 来源页面：`https://historymuseum.nju.edu.cn/info/3061/69011.htm`
- 校徽原图：`/__local/8/D1/36/80BA42FDEAF0EFC33128F2704AE_A8B786CF_3D81E.jpg`
- 书法字标原图：`/__local/3/EA/E5/0217EB822396457731B80ABECFF_99B235CD_EA525.jpg`
- 获取日期：2026-11-15

处理步骤：下载公开页面所列 JPG，去除白色背景、裁去多余白边，分别保存为 `emblem_mark.png` 与 `brand_lockup.png`；没有重绘校徽，也没有改写书法字形。字标保留原图的紫色。主题配置保留 `BRAND_SOURCE.json` 中的页面 URL 与站点相对路径，避免依赖本机临时目录。
