# 求是蓝主题来源

## 官方身份资产

- 浙江大学校标页面：<https://www.zju.edu.cn/514/listm.htm>
- 浙江大学校名页面：<https://www.zju.edu.cn/576/listm.htm>
- 主题使用用户下载的校标、校名图片组合成透明 `brand_lockup.png`。
- 不重绘、不改写校标内部文字；仅从白底提取透明度并统一为官方求是蓝。

## 官方色值

- 求是蓝：`RGB(0, 63, 136)` / `#003F88`
- 创新红：`RGB(176, 31, 36)` / `#B01F24`

求是蓝用于结构、标题和身份层；创新红只用于关键风险、边界或需要强调的数字，不作为大面积装饰色。

## 使用边界

- 正式提交前应以学校最新视觉识别规范复核校标、校名组合与留白。
- 主题不伪造学院 Logo、校训书法、签章或任何未经提供的官方标记。
- `brand_lockup.png` 只用于本主题的页眉和封面身份层，不用于生成式图像提示词。
