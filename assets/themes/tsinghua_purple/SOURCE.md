# Tsinghua Purple Theme Sources

- Theme type: Tsinghua University doctoral proposal example.
- Primary color: Tsinghua purple (`#5B0B63` family).
- Emblem source page: `https://www.urongda.com/logos/tsinghua-university`
- Emblem file used: `https://www.urongda.com/images/normal/medium/tsinghua-university-logo-1024px.png`
- Official lockup source: `https://vi.tsinghua.edu.cn/image/logo296.png` (Tsinghua Visual Identity page).
- The official horizontal lockup uses the school's calligraphic wordmark. It was cropped to the seal plus `清华大学` and recolored to the theme purple.
- Regenerate with `scripts/build_brand_lockup.py --lockup ... --lockup-crop 0,0,236,88 --recolor-lockup`.

The emblem is a school identity asset. It is included only so this example can render a recognizable Tsinghua deck. Before public or commercial use, confirm that your use complies with Tsinghua University's visual identity rules. The repository and this skill are not affiliated with or endorsed by Tsinghua University.
