# 中文答辩 / 报奖 PPT 的风格区间

这份文档来自对一套「省科学技术奖答辩」模板（编号 647）三页截图的**像素测量**，
不是观感描述。测量的目的只有一个：给主题作者一组可以对照的数值范围，避免「深蓝」被写成 `#0F3D73` 这种闷到发黑的色。

## 配色区间（可用范围，不是唯一解）

对三张图的彩色像素（饱和度 > 0.30）做聚类，三页结果高度一致：

| 角色 | 实测值 | 色相 | 说明 |
|---|---|---|---|
| 主色（标题条、强调块） | #164C9C / #194F98 / #1A4E9B | **H 214–216°** | S 83–86%，V 60% |
| 深色（页眉底、深色块） | #2F4E79 / #37567D / #476A9A | H 213–215° | V 47–49% |
| 中间色（次级条、图标） | #5679A1 / #6B8AB4 | H 212–215° | S 40–56% |
| 浅色（底纹、卡片填充） | #7A9ECD / #8AAACF | H 212–214° | V 71–81% |
| 强调红（风险、结论、关键数） | #A52E2D / #A94447 / #AE5B55 | **H 0–4°** | S 60–73% |

### 硬性区间

- 主蓝：`H 213–217°`、`S 78–88%`、`V 55–64%`。
  低于 V 50% 会开始发闷（`#0F3D73` 就是 V45%，属于过深）；高于 V 68% 会变亮蓝，失去「机构色」的稳重感。
- 强调红：`H 355–5°`、`S 55–75%`、`V 58–70%`。偏橙或偏洋红都会破坏与主蓝的对比。
- 灰色系统保持低饱和（S < 12%），否则和主蓝抢注意力。

## 结构约定

1. **卡片带标题条**：参考页里每个模块都是一条深蓝色标题条 + 白底正文，
   而不是「白底 + 细描边」。主题里写 `panel.header_style = "gradient"`（渲染器默认值）。
   把它改成 `flat` 会立刻变成另一种风格（更像西文期刊 slides），**并且 PPTX 导出器不读这个开关**，
   只在 PNG 预览里生效，会造成预览与交付件不一致。
2. **不用圆形图标徽章**：参考用的是小箭头、示意图、表格式图元。
   每块顶一个圆图标是「仪表盘感」的来源，主题里置 `layout.block_icons = "off"`。
3. **导航先选模式**：参考页靠「章节号 | 标题」加页码导航，没有常驻侧栏。
   短 deck 选 `meta.navigation_mode: "sidebar"`；长 deck 需要明确章节转场时选 `"dividers"`；
   长 deck 同时需要章节转场和局部定位时选 `"hybrid"`。`hybrid` 的侧栏要求正文左边界 ≥ 300 px，
   否则渲染器会跳过目录避免压字。不要再让用户直接改 `layout.sidebar_mode`。
4. **信息密度高于西文模板**：这类答辩页常见「四张卡 + 两级嵌套」。
   拿它和学校形象模板（每页 9 个元素）比密度是不公平的；密度指标只适合和同类答辩 deck 比。

## 与 `cn_defense` 主题的对应

`assets/themes/cn_defense/theme.json` 就是按上表落地的：

```json
"blue": "#1A4E9B", "blue_dark": "#123A75", "blue_mid": "#4A6FA5",
"blue_bright": "#6E8FC7", "blue_pale": "#DCE6F3", "red": "#A82F2E"
```

验证方法（别只看代码，要看渲染结果）：把渲染出的 PNG 用同一套聚类脚本跑一遍，
主色应该落在 `H 214–217 / S 78–86 / V 55–62`。实测 `#20529C`（H216 S79 V61）符合。

## 边界

- 本文件不包含那套模板的任何图片、图标或文字，只记录数值区间与结构约定。
- 数值来自 JPEG 截图，已有压缩损失，色相可信、饱和度略偏低；实际取色时按区间中值选即可。

## 版面骨架的成本表（实测）

拿一份 13 页 deck 逐页数过，一个「图 + 两块面板」的页面是 31 个对象，其中**真正的内容只有 5 个**：

| 层 | 对象数 | 是否可删 |
|---|---|---|
| 背景纹理 + 页眉标题 + 章节号 + 机构名 + 两条分隔线 | 7 | 保留（身份层） |
| lead 底板 + 左侧色条 + 四角折角 ×4 + 正文 | 7 | 折角可删（4） |
| 内容区大框 | 1 | 可删 |
| 真图 | 1 | 保留 |
| 每块面板：底板 + 标题条 + 高光条 + 分隔线 + 序号 + 标题 + 正文 | 7 | 高光、分隔线、序号可删（3/块） |
| 脚注 | 1 | 保留 |

也就是说：**这套渲染器的固定成本约 20 个对象，内容只占 5–10 个**。
同类真人 deck 的 15.8 意味着它几乎没有这层固定成本。
把 `panel.*` 的四个装饰开关和 `layout.lead_panel` 关掉，能把固定成本降到 ~12，全页 ~21。
再往下就只能删内容或换渲染器，不属于「调参数」的范围。
