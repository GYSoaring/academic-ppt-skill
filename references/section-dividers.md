# 章节分隔页：蓝带 + 跨带大数字

这套版式来自一份真实的中文答辩模板（用户实拍，991×620）。所有比例是量出来的，不是估的。

先区分三件事：

- **目录页**：`layout: "outline"`，全篇只有一张的汇报提纲。
- **章节分隔页**：`layout: "section"`，本文档讲的整页蓝带版式，每章前插入一张。
- **侧栏目录**：内容页左侧常驻的五项 mini-directory，由 `layout.sidebar_mode` 控制，不是分隔页。

## 何时使用 / 何时不用

使用：

- `meta.navigation_mode` 选 `dividers` 或 `hybrid`；
- 16 页以上的答辩、课程或长报告，现场需要清晰的章节转场；
- 每章有 3 页以上的独立论证，值得用整页换一次节奏。

不要使用：

- `meta.navigation_mode: "sidebar"`：这种 deck 靠左侧常驻目录导航，不应再插整页分隔页；
- 10 页以内的线性短汇报：分隔页会压缩有效内容；
- 只想“多一张好看的过渡页”而没有真实章节边界：先修章节结构。

三种导航模式与低层字段的对应关系：

| `meta.navigation_mode` | 章节分隔页 | `layout.sidebar_mode` |
|---|---|---|
| `sidebar` | 不插 | `always` |
| `dividers` | 每章一张 | `off` |
| `hybrid` | 每章一张 | `section`（仅每章第一张内容页显示侧栏） |

## 版式

```

│ [校徽+校名]                       校训        │  ← 页眉（无标题）

│                                              │
│                                    ╭────╮    │
│                             02  （渐变数字）  │  ← 跨带，上深下浅

│  │ PRINCIPLE OF OPTICAL RECTIFICATION     │   │
│  │ ─────────────────────────────────── ● │   │  ← 细线 + 右端圆点
│  └───────────────────────────────────────┘   │
│                                              │
└──────────────────────────────────────────────┘
```

## 实测比例（页高 / 页宽为 1）

| 元素 | 位置 | 尺寸 |
|---|---|---|
| 页眉细线 | y = 0.19 | 通栏，左右各留 2% |
| 蓝带 | y 0.46 → 0.855 | 左起 0，右端停在 **0.968**（留白 3%） |
| 中文标题 | 带内 y = 0.24 × 带高 | 100 px（2048 画布），白色粗体 |
| 英文标签 | 标题下 18 px | 38 px，白或 75% 白 |
| 细白线 | 距带底 0.19 × 带高 | 从 104 到 0.90w，右端一个 14 px 圆点 |
| 大数字 | x = 0.605，y = 0.222 | 宽 0.335w，高 0.44h，**跨带叠压** |

**关键不是「数字压在带子上」，而是跨带**：数字上半落在白底（深蓝），下半落进蓝带（浅蓝）。这个叠压关系是整页唯一的亮点，做平了就没味道。

## 数字的渐变怎么做

- **PNG 路径**：先用文字画一张 L 蒙版，再做一条纵向渐变（`blue_dark` → 偏白），用蒙版贴上去。
- **PPTX 路径**：PowerPoint 不给文字上渐变。所以生成一张**透明底的渐变数字 PNG**（`assets/section_number_01..05.png`）当图片放进去。两条路径必须同尺寸、同位置，否则预览和交付会对不上。

## 必填/可选项

| 字段 | 必需 | 说明 |
|---|---|---|
| `layout: "section"` | 是 | 触发这套版式 |
| `section` | 是 | 对应 `sections[].id`，序号由它自动推出 |
| `title` | 是 | 中文标题 |
| `label_en` | 否 | 大写英文标签；没有就不画 |
| `theme.brand.motto` | 否 | 页眉右侧的校训，如「学为人师 行为世范」 |

## 自动插入

```bash
python scripts/add_section_pages.py --deck deck.json --out deck.json
python scripts/add_section_pages.py --deck deck.json --navigation-mode dividers
```

按 `sections` 顺序在每个章节第一次出现前插一张分隔页，已存在的跳过（可重复运行）。它同时补上 `label_en`（从 `sections[].label_en` 读，没有就用章节名首字母推导）。脚本读取 `meta.navigation_mode`：`sidebar` 模式直接跳过，`dividers` / `hybrid` 正常插入；命令行显式传入 `--navigation-mode` 时会把该值写回 `deck.json`。

## 校验注意

分隔页是**整页独立版式**，不承载页眉身份与页脚。`validate_deck.py` 对 `layout: "section"` 的页面豁免「上部身份像素一致」和「页脚像素一致」两项检查——它们只对内容页有意义。
