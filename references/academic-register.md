# 学术语体与结构（中文 deck 版）

两个来源：`zLanqing/codex-claude-academic-skills`（6.0k★，论文写作）与 `AIScientists-Dev/academic-humanizer`（5.3k★，去除 AI 写作痕迹）。这里把它们改写成中文 PPT 能直接用的规则。

## 一、结构：综述不是「介绍」，是「评述」

文献综述必须有**可检验的判断**，不能只按时间或作者罗列。固定五段：

| 段 | 内容 | 页面上必须出现的东西 |
|---|---|---|
| 1 问题与范围 | 要回答什么问题；检索来源、关键词、时间窗、纳入/排除标准 | 范围界定 + 承认检索局限 |
| 2 现状（分路线） | 每条技术路线单独讲：代表工作、方法要点、已知局限 | 具体工作 + 局限，不写「很多研究」 |
| 3 横向比较 | 用统一维度比较；**不做没有共同基准的精度排名** | 比较表 + 为什么不做排名 |
| 4 共识与分歧 | 各路线共享什么假设、在什么上分歧 | 归纳（标明是作者判断） |
| 5 空白与展望 | 哪些问题文献没解决；下一步怎么做 | 可执行的下一步 |

汇报单页对应关系：一页一个论点，页面 = `claim`（结论）+ `evidence`（证据）+ `boundary`（边界）。缺 `boundary` 的页，读起来就是宣传。

## 二、语体：11 类 AI/口语痕迹（中文对照）

| 类 | 不要写 | 改写成 |
|---|---|---|
| 过度断言 | 证明了、确立了、确保了 | 给出证据表明；在 X 条件下观察到 |
| 意义吹捧 | 开辟新途径、奠定基础、具有重要意义、填补空白 | 具体说明解决了哪个失效模式 |
| 空洞强度词 | 显著提升、大幅改善、效果很好 | 给出数值、基线、条件；无数据就删 |
| 首创标榜 | 首次提出、据我们所知 | 说明与前人工作的差别在哪 |
| 套式开头 | 随着…的快速发展、近年来…受到广泛关注 | 直接写结构性事实或矛盾 |
| 连接词堆砌 | 此外、而且、同时、另外（连续三句） | 让逻辑自己走，句间不靠连接词 |
| 贡献清单 | 本文的主要贡献是：①…②…③… | 每条贡献绑定一个具体结果 |
| 引用倾倒 | 已有大量研究[3,7,9,12] | 只引一两篇关键工作，并说明为什么相关 |
| 模糊限定 | 一定程度上、某种程度上、相对较好 | 量化，或删掉 |
| 模板强调 | 值得注意的是、需要强调的是、众所周知 | 重要的话本身就能体现 |
| 超长句 | 三个以上从句套在一句里 | 一句一个意思，砍掉没有信息量的从句 |

## 三、中文口语标记（PPT 正文里一律不出现）

各位老师、大家好、我们来看、其实、就是说、那么、呃、挺好的、好多、特别、非常、超级、基本上、大概、差不多、这块、那块、搞定、弄、做一下

这些词可以留在**讲稿（speech）**里，因为那是口语；但**页面上的文字**必须是书面语。

## 四、每条主张都要能落到文献

- 引用要具体：「已有研究表明」= 没写。「X 等人在 2023 年报告了 Y」= 写了。
- 描述别人工作时，只写**标题与摘要能支撑的内容**，不推测实验细节。
- 自己归纳的结论必须标 `个人判断`，与文献结论分开。
- 检索范围有缺口就明说（例如只检索 arXiv、未覆盖期刊库）。

## 五、自检顺序

1. `scripts/lint_register.py` 扫语体（口语、hype、空泛、模糊限定）。
2. 逐页问：这一页的 claim 是不是判断句？evidence 有没有具体工作或数字？boundary 写没写？
3. 问：把这一页删掉，论证会断吗？不会断就删。
4. 问：换成同领域另一位作者，他会同意这页的哪句话、反对哪句？答不出来说明写空了。
