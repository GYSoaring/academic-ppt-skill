# 目录页：单列五行铺满版心

`layout.outline_style: "index"`。比例来自一份真实渲染（用户截图），不是估的。

## 版式

```
                                    C O N T E N T S
 │
 │ 01  光密度到血氧的反演
 │     修正的比尔-朗伯定律与三类测量体制
 │     ────────────────────────────────
 │ 02  三类体制与信号链
 │     四步信号链与滤波的关键取舍
 │     ────────────────────────────────
 │ 03  …
```

- 左侧一条 3 px 竖线做骨架，从第一条到条末
- 序号：**112 px，实色主色**（不是淡色——淡色在白底上几乎看不见）
- 章节名 62 px 粗体，下面一行 30 px 灰字说明（`sections[].desc`）
- 行间一条细横线，右端起于标题左沿
- 右上角 `C O N T E N T S`，34 px，字距拉开

## 关键：铺满，不要挤在上半页

几何必须由页眉与页脚推出来，不能写死起点：

```
top     = header_height + 48
bottom  = footer_y - 48
row_h   = (bottom - top) / 章节数
```

写死起点（例如 `top = 520`）会让五行挤在下半页，上方留下近 600 px 空白——这是这一页「丑」的最常见原因。判断方法：把渲染图按 12 条横带统计墨迹，若前 4 条带全为 0，就是没铺满。

也不要两列。5 个章节排两列会变成 3+2，右下角留一个洞。

## 字段

| 字段 | 必需 | 说明 |
|---|---|---|
| `layout: "outline"` | 是 | |
| `sections[].title` | 是 | 章节名，6–18 字 |
| `sections[].desc` | 否 | 说明行；没有就少一行，行高不变 |
| `layout.outline_style` | 是 | 填 `index` |

## PNG 与 PPTX 必须同几何

预览在 PNG 上做，交付是 PPTX。两边的 `top / row_h / 字号` 必须是同一组数值，否则预览不能预测交付。校验方式：导出的 pptx 首行 `top` 应约等于 `top_y × 0.625`（2048 画布 → 1280 pptx），行距同理。

## 自检

1. 12 条横带里，前两条是否只有页眉？
2. 五行是否等距、最后一行是否落在页脚上方？
3. 序号颜色对比度够不够（白底上淡蓝 ≈ 看不见）？
4. 标题与说明是否左对齐同一列？
